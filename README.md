# AutoGest-Concession-ria

Sistema de Gestão de uma Concessionária de Veículos



Descrição do Projeto



O AutoGest é um sistema desenvolvido para auxiliar no gerenciamento de uma concessionária de veículos.



Objetivo



Facilitar o controle de veículos, clientes, vendedores e operações de vendas.



Funcionalidades



Cadastro de veículos.



Cadastro de clientes.



Controle de estoque.



Registro de vendas.



Consulta de veículos disponíveis.



Ferramentas



GitHub



GitHub Desktop



Python



Status do Projeto
